# MP продвижение (`modules/mp`) — статус и контекст

> Краткая сводка для продолжения работы. Модуль = фронт для управления
> выкупами/регистрацией на маркетплейсах (пока платформа одна — Wildberries).
> Всё пока на **мок-данных** (тестовый сервер), бэкенда нет.

## Файлы
- `mp.html` — оболочка: главный сайдбар-модуля (список серверов, выдвижной), шапка-сегмент (4b), рабочая область с 7 вкладками (панами), модалка.
- `mp.js` — объект `MP`, вся логика/рендер вкладок.
- `mp.css` — стили (свои токены light + общие атомы).
- `manifest.json` — `{id:"mp", name:"MP продвижение", icon:"mp", min_role:"immortal"}`.
- Иконка `svg/mp.svg` (витрина). Цвет/подсветка синие — в `core/shell.css` (шар в кольце навигации, оттенок в `SideNav.jsx`).

## Дизайн-система (важно)
- Шрифт **Manrope** (подключён в `core/shell.css` @import; на формах `font-family:inherit`).
- Свои light-токены на `.mp-sys` / `.mp-ord-wrap` / `.mp-wu` (`--o-text` и т.д.), SF fallback.
- **Общие переиспользуемые атомы** (эталон — вкладка Покупки):
  - `_client(name,phone,gender)` / `_gAva(g)` — аватар пола + имя + телефон.
  - `_ordItems(r)` — превью фото товаров + поповер (клик по фото → товар в WB).
  - `_ordAddr(r)` — усечённый адрес + поповер с полным.
  - `_execStatus(exec,label?)` — иконка+цветной текст (done/running/pending/error) + `_execNotch()`.
  - `_lstatus(status)`/`_lstatusC(text,cls)` + `_lnotch()` — точка+цветной текст.
  - `_photoLink(article,size,cls)` + `_wbUrls(article,size)` — картинка/ссылка Wildberries из артикула (имя wb здесь про площадку, не про модуль) (без запросов, формула vol/part).
  - Кнопки `.mp-b .mp-b-primary|neutral|danger` (объёмные, primary зелёная). Бордер убран.
  - Чекбокс `.mp-check`. Лоток кнопок `.mp-btn-tray` (вдавленный) и `.mp-pk-act` (группа кнопок в строках, фон `#f7f7f936`).
  - Табличный вид: `.mp-lcard`/`.mp-lcard-head`/`.mp-lgrow` (одна карточка, как в Прогреве) — сетка колонок задаётся inline.
- **НЕ использовать** hover-подсветку через `border-color` (просили убрать везде).

## Вкладки (все переведены на light-табличный вид)
1. **Аккаунты** — глобальный список. notch по статусу, `_client`, товары/адрес (могут отсутствовать → «—»), счётчики покупок/отзывов, «Последний вход» (Сегодня в HH:MM / вчера / N дней назад). Поиск (имя/номер/артикул/статус/адрес). Панель выбора появляется в верхней панели справа (лоток, анимация `.mp-appear` только при смене режима).
2. **Регистратор** — реальное состояние per-server (`_regStore[srv].pool/active`). «Запланировать[: N]» переносит из Доступны→Активные (время по дню, статус pending) + облако. Активные: exec-статусы, чекбоксы + «Снять на сегодня». Пол не показывается (ещё не распределён). Архив убран.
3. **Прогрев** (вариант 5b) — read-only, notch/чекбоксы/«Снять на сегодня» с подтверждением. Сортировка по времени.
4. **Покупки** (эталон OrderRow) — 4 состояния (in_progress/error/paid/scheduled), группировка по статусам, поиск, фильтр-лоток `mp-ord-stats`, статистика, банк-пилюля (Оплатить→«Выхожу на оплату»→QR+красный таймер 4 мин), форма «Изменить» с tag-input.
5. **Получение** — под-вкладки Получение/Доставка, код (340 193), фильтр города (из аккаунтов), экспорт `.xls` (HTML-таблица с QR-картинкой; имя `получение_{город}_{дата}`). QR — плейсхолдер из кода.
6. **Отзывы** — сетка карточек (средняя картинка) + список/план/архив (tm фото, текст отзыва в строке).
7. **Статистика** — KPI/бары (мок).

## Серверы
- Группируются по платформе (группа = платформа). Добавление сервера: выбор платформы (`_PLATFORMS=['Wildberries']`) + название. Тестовый сервер `_buildTest()` = 30 аккаунтов, 8 городов, 7 товаров с реальными артикулами, платформа Wildberries.

## Уведомления — облако у аватарки (в `core/shell.js`)
- `Shell.notify({text, action:{label,fn}, persistent, id, duration})` — облако мысли от аватарки профиля, объёмное, анимация появления/исчезновения, авто-скрытие 5с (кроме hover), крестик. `persistent:true` (обновление приложения) — без крестика, висит до нажатия «Обновить».
- `Shell.dismissCloud(id)`. **Важно:** был баг — `window.Shell` не выставлялся (const), из-за чего все `window.Shell && ...` в модуле молчали; исправлено (`window.Shell = Shell`).
